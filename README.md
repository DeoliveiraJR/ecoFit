# EcoFit

Aplicativo mobile de saúde, bem-estar e acompanhamento de hábitos para o setor ECOA.

## Objetivo

Promover qualidade de vida através de:

- Acompanhamento de treinos
- Hábitos saudáveis
- Metas pessoais
- Agendamento de massoterapia
- Inteligência artificial conversacional

## Mascote

**CapyCoach**

Capivara atleta, nerd e especialista em tecnologia responsável por guiar os usuários na plataforma.
